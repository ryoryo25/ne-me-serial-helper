# ne-me-serial-helper

≠ME（ノイミー）の CD 特典応募シリアルナンバーを、まとめて入力・送信するためのヘルパーツールです。

複数のシリアルナンバーを一括で入力し、必要な個人情報をフォームに一度だけ記入すれば、すべてのシリアルに対する `curl` 送信スクリプトを自動生成できます。

## 対応シングル

| シングル | フォルダ | ファイル | 備考 |
|---|---|---|---|
| 11th『排他的ファイター』Type-A, C | `11th/` | `ac.html` | index.html からはコメントアウト済み |
| 11th『排他的ファイター』Type-B | `11th/` | `b.html` | index.html からはコメントアウト済み |
| 12th『愛くださいませ/ここでファーストキッス』Type-A, C | `12th/` | `ac.html` | **対応中** |
| 12th『愛くださいませ/ここでファーストキッス』Type-B | `12th/` | `b.html` | **対応中** |

## 使い方

1. `index.html` をブラウザで開く
2. 応募したいシングル・タイプを選択
3. フォームに必要事項を入力
   - **シリアルナンバー**: テキストエリアに 1 行 1 つずつ入力（8 桁の英数字）
   - **プレゼント番号 / メンバー選択**: シングルごとに異なる選択肢
   - **個人情報**: メールアドレス、氏名、フリガナ、年齢、性別、郵便番号、住所、電話番号
4. 「確認」ボタンで入力内容をプレビュー
5. 「curl スクリプト作成」ボタンでシェルスクリプトを生成
6. 「コピー」ボタンでクリップボードにコピーし、ターミナルで実行

### 便利な機能

- **郵便番号から住所を自動入力**: 郵便番号を入力して「住所を自動入力」ボタンを押すと、[zipcloud API](https://zipcloud.ibsnet.co.jp/) を使って都道府県・住所を自動補完します
- **申込期限の自動制御** (12th Type-A, C): 期限切れのプレゼント選択肢は自動的に非表示になります
- **条件付きフィールド表示** (12th Type-A, C): プレゼント番号に応じて、会場選択やメンバー選択のフィールドが動的に表示されます
- **シリアルのバリデーション**: 8 桁の英数字であるかを自動チェックします

## 開発用モックサーバ

`mock-server.js` を使うと、ローカルで送信テストができます。

```bash
node mock-server.js          # デフォルト: ポート 3000
node mock-server.js 8080     # ポート 8080 で起動
PORT=8080 node mock-server.js  # 環境変数でもOK
```

すべての HTTP リクエストの内容（ヘッダ・ボディ）をターミナルにそのまま表示し、常に `200 OK` を返します。CORS ヘッダ付きなのでブラウザからの直接送信テストにも対応しています。

## 新しいシングルの追加方法

1. 新しいフォルダ（例: `13th/`）を作成
2. 既存の HTML ファイル（例: `12th/ac.html`）をコピーして編集
3. `<script id="single-config">` 内の JSON を更新:
   - `formNameMap`: 各フォームフィールドと送信先のパラメータ名のマッピング
   - `fixedValues`: 送信時の固定パラメータ
   - `defaultEndpoint`: 送信先 URL
   - `conditionalFieldsets` (任意): プレゼント番号に応じた条件付き fieldset の制御
4. `index.html` のリストにリンクを追加

## 技術的な仕組み

### アーキテクチャ

フレームワーク不使用の静的 HTML + バニラ JavaScript で構成されています。

- **`common.js`**: 全シングル共通のユーティリティ（`window.SerialHelper` に公開）
  - 都道府県名→コード変換 (`prefNameToCode`)
  - 性別→コード変換 (`genderToCode`)
  - シリアル形式バリデーション (`isValidSerial`)
  - 郵便番号→住所検索 (`lookupZip`, zipcloud API 使用)
- **`form-engine.js`**: 各ページの `<script id="single-config">` から設定を読み取り、フォームの動的制御・curl スクリプト生成を行うエンジン

### 送信データの形式

| フィールド | 送信時の変換 |
|---|---|
| `prefecture` | 都道府県名 → 都道府県コード（1〜47） |
| `gender` | `男` → `1`, `女` → `2` |
| `zip` | `zip1`（3 桁）, `zip2`（4 桁）に分割 |
| `tel` | `tel1`, `tel2`, `tel3` に分割 |
| `agree` | チェック時 `1` |

### 生成される curl スクリプト

生成されるシェルスクリプトは、入力されたシリアルナンバーごとに `curl -X POST` を実行し、各リクエスト間に 10 秒のスリープを挟みます。
